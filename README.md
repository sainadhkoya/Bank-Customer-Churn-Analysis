# Customer Segmentation & Churn Analysis in European Banking

## Objective
Analyze bank customer data to identify churn patterns across geography, age, balance, and engagement levels.

## Tools Used
Python, Pandas, Seaborn, Matplotlib, Streamlit

## Key Findings
- Inactive members churn more frequently
- Germany region shows highest churn rate
- Low tenure customers are high risk
- Balance and engagement strongly affect retention

## Project Components
- Data Cleaning & Segmentation
- Churn Pattern Analysis
- Visualization Dashboard

## Dataset Features
CreditScore, Geography, Age, Tenure, Balance, Products, Activity Status, Salary, Churn

## Outcome
Helps banks identify high-risk customers and design retention strategies.
